# Sprite Offset

Lightweight Android sprite offset viewer and editor for classic Doom-family game graphics.

## Project status

The first milestone focuses on image selection, transparency preview, zoom, preview modes (Auto, Graphic, Sprite, HUD), and editable X/Y offsets. Doom-specific patch readers/writers and format conversion will follow in later milestones.

## Build

GitHub Actions builds a debug APK on pushes to main and supports manual runs. The APK is published as a workflow artifact.

## Android
- Minimum Android: 8.0 (API 26)
- Language: Kotlin
- UI: Native Android views and custom Canvas preview
